# Subutai V1 — повний чек-лист перевірки перед злиттям і запуском

Гілка: `release/v1-neon` (створена від `main` @ 28085b9 — тобто містить
**усе з main** плюс роботу V1; окремо тестувати main не треба).

Як користуватись: іди зверху вниз, відмічай. Позначки:
**[A]** — я вже перевірив автоматично/живцем на цій гілці, тобі варто
глянути очима. **[U]** — може перевірити тільки ти (потрібен другий
пристрій, акаунт, деплой або смак). **[BLOCK]** — блокує запуск.

## 0. Передумови

- [ ] `npm install` (якщо гілка свіжа)
- [ ] `npm run dev` → `http://localhost:5173/subutai/`

      `http://localhost:4173/subutai/`

- [ ] En passant працює і зникає після ротації.

## 17. Відомі обмеження (не блокують запуск)

- Легальність ходів у мультиплеєрі досі довіряється клієнту: правила
  закривають хід не в свою чергу і переписування логу, але не шахову
  легальність. Повне рішення — Cloud Function.
- `App.tsx` монолітний (~6.5k рядків), рефакторинг після релізу.
- Немає автотестів крім двох скриптів; Vitest — після релізу.
- Spotify-embed без логіну грає 30-секундні прев'ю (обмеження Spotify).
- Анонімні акаунти: очищення сховища браузера втрачає ім'я і статистику.
- Хінт-пошук ~800 мс на головному потоці (DEF-7).
